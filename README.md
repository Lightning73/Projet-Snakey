# Projet-Snakey

Je sais il faut que je fasse un plus joli ReadMe, mais voilà c'est un début

Snakey est un jeu de Snake, implémenté sur une FPGA en utilisant le logiciel Quartus Prime et une Ardino pour la gestion du Jotstick
Le projet est utilisable après avoir été dézippé. Il faut brancher la carte FPGA à l'arduino et les 2 au PC, puis connecter le joystick à l'arduino. Le code arduino est dans le dossier Ardino_DE1_Test.
